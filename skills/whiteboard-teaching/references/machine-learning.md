# 机器学习主题的条件规则

只有用户目标与资料确实涉及模型计算、训练、概率或校准时读取适用部分。本文不规定每张图都包含这些机制，不规定基座、决策头、阶段数量或模型名称；新模型图同样先按 authoring 做逻辑规划。

## 架构与比较

先区分已知功能接口与内部实现，核对指定文献或源码的版本。数据、模型表示、预测输出与训练目标分开；公开 API 不能证明闭源系统使用何种编码器或评分器，开源重现也不是其内部事实。

整体模型、编码器、任务模块与内部算子采用不同层级。展开编码器内部时保留整体名称与职责；只有实际实现确认时才用 BERT 等具体名称。不同模型的共同职责可以一致，基座、输入组织、表示读取与输出机制不必相同。

只在资料支持时使用以下局部图形模式：

- 多候选评分：若确有共享评分模块，候选表示进入同一模块，输出分数及对应概率；不推定所有模型都独立评分或共享相同模块。
- 数据表示：用通用对象的形状、字段或维度变化说明处理过程；位置读取、池化、匹配或生成步骤按照实际结构区分。
- 推理与训练：确实存在两种过程时分别画出使用的数据、可训练参数与反馈方向，不让读者以为每次请求都重新训练。

## 训练与反馈

只有讲解目标需要训练机制时才展开预测、目标、损失或奖励、参数更新。梯度或反馈回到实际可训练对象；停止梯度、默认权重、可选分支、冻结模块与损失组合核对指定源码。

扰动或搜索存在时，从同一状态展开资料支持的方向、比较与更新；不凭模板添加固定数量的候选或扰动。区分训练奖励、概率损失与最终任务成绩，不声称训练目标已经保证泛化性能。

## 概率与校准

区分原始分数、转换后的概率、校准映射与业务决策。核对任务是互斥单选、多标签、评分或其他输出，不能对所有输出套用 softmax 或总和为1的约束。

校准确实存在且属于讲解目标时，说明拟合所用数据、改变的对象、保持不变的对象与适用条件。训练、校准和独立评估的数据边界核实后再绘制，不能以通用教学框架冒充模型实际训练流程。

## 公式与示例

保留决定机制的公式，并就近说明输入输出、符号、下标、范围、条件、单位或维度。具体求和、权重、温度、停止梯度和更新式回到指定资料核对；公式编辑技术见 [tools.md](tools.md)。

主图先展示通用对象与抽象接口。用户要求数值算例时，用独立附属区展示中间计算，明确假设并独立复算概率、损失等数值；没有运行模型的数字不能称为实测。业务例子不取代输入输出定义。

默认配置、可选机制、教学简化、论文主张、项目实现与实验结果分开。不把一般分类或校准表现当成未经验证的下游任务优势。
