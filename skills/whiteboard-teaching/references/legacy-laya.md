# Laya 历史文稿兼容

仅维护已读取且具有下述历史前缀或布局标记的旧文稿时使用。主题提到 Laya、BERT 或模型不构成触发条件。先核对真实图元、结构、锁定状态与当前 UI 是否仍提供对应按钮；缺少条件时用新版局部编辑，不重新建立历史模板。

## 历史定位与批次

旧版主区域使用 `teach-n-title`（n=1,2,3），成员 alias 以 `teach-n-` 起始。服务生成 `ai-UUID-alias`，导航依据前缀与原生绑定文字找区域；不手工改最终 ID。旧实现将标题与成员放同一 items 批，取最近的三主区，再按 y、x 排序。

历史详解使用 `detail-1-title` 至 `detail-6-title`，成员共用 `detail-n-` 前缀，标题以 A 至 F 标记。旧导航保留三主区，并附加最新详解；旧课程的详解不加入新课程导航。以上是旧稿识别信息，不是新版生成要求。

维护旧结构时保留其名称、归属与内容。旧外框是不带 text 的 rectangle，空框省略 text。旧双行节点至少104px的经验来自当时字号，当前应按真实字体测量。

## 历史布局操作

历史“主次布局”仅适用于约定结构齐全且没有区域外绑定的教学图，经原生一次撤销保存。主线居中，外围详解使用轻框与字母虚线；旧字母聚焦可至200%。这些不是 MCP 缩放参数，旧手工引导线不保证任意拖动后跟随。

旧“详解＋”曾将外围详解由0.6调至0.75原尺度，正文由约15.6变为19.5画布像素，主线保持1.6倍。以面对主线的边中点为锚，原引导线终点不变；完成后按钮隐藏且不累计放大。它属于特定三主区六详解示例，不推广到其他课程。

2026-10-11 的旧“优化排版”模板使用主节点50、详解正文与节点28、公式文字30、标题34、来源22；根据字体测量重新安排框体、边中点直角线与外围引导。整批一次撤销，重复不累计。它只支持对应旧结构中的公式文字，不支持新版带源码的公式 image；出现公式 image、锁定对象、旋转、外部绑定或测量期间画布变化时中止。

不要以删除、新建整板或纯文本替换来规避旧模板限制。允许的局部操作以当前 [tools.md](tools.md) 为准；更新公式 image 使用其源码与专用公式操作。

## 历史坐标参考

下表仅用于理解旧稿的留白与测量基线，不是新图模板。旧表左边界 x=100，顶部 y=已有内容下界+160。

| 内容 | 相对位置 | 当时参考 |
| --- | --- | --- |
| 标题 | (0,0) | 40px，一行 |
| 核心问题或例句 | (0,78) | 26px，最多两行 |
| 主节点 | (0,185)、(440,185)、(880,185) | 350×130，最多三行 |
| 节点说明 | 节点下方42px | 24px，每行约13个中文字，最多三行 |
| 例子或结论 | (0,480) | 26px，最多三行 |
| 来源与假设 | (0,610) | 20–22px，最多两行 |

旧四节点横排曾用宽270、间隔60、总宽1260。当前修改先核对最长文字、真实换行与连接，再决定尺寸，不强制继续使用旧表或恢复业务例子。

## 新版兼容操作

缺少 region 声明的外框，后续追加仍可能被碰撞保护拒绝。可先 set_region 声明空矩形，再给成员加入 regionId；它不是原生 frame。旧独立公式文字可按 tools 转换，未支持对象不转换。

新导航使用 region.kind、order、lessonId 与 parentId。维护旧稿无需为导航而整板重建。board_patch、preview、render 和 validate 仍使用本次读取的 boardId、editorSessionId 与最新版本；工具定义不足时明确说明，不能绕过校验。
